利用規約・プライバシーポリシー

制定日：2026年11月15日

1. このサイトについて

「わんこガチャ」(以下「本サイト」)は、YouTube に公開されている再生回数の少ない犬の動画をランダムに紹介するサイトです。本サイトは YouTube API サービスを利用しています。本サイトは YouTube および Google とは関係のない個人が運営しています。

2. 利用規約

  • 本サイトを利用することで、YouTube 利用規約に同意したものとみなされます。
  • 紹介している動画の著作権は、それぞれの投稿者に帰属します。動画の内容について、運営者は責任を負いません。
  • 動画は自動で選んでいるため、意図しない内容が表示される場合があります。不適切な動画を見つけた場合は、お問い合わせ先までお知らせください。
  • 本サイトは予告なく内容の変更や公開の停止を行う場合があります。

3. YouTube API サービスの利用

本サイトは、YouTube API サービスを通じて、公開されている動画のタイトル、チャンネル名、再生回数、高評価数、コメント数、投稿日、長さなどの情報を取得し、紹介する動画を選ぶために使用しています。これらの情報は定期的に更新し、削除・非公開になった動画は紹介の対象から外します。

YouTube および Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。

4. 利用者の情報の取り扱い

  • 本サイトは、氏名・メールアドレスなどの個人情報を収集しません。会員登録やログインの機能もありません。
  • 同じ動画が続けて出ないように、一度表示した動画のIDを利用者のブラウザ内(ローカルストレージ)に保存します。この情報は利用者の端末にのみ保存され、運営者に送信されることはありません。ブラウザのサイトデータを削除すると消去できます。
  • 「犬じゃなかった」ボタンを押すと、その動画のIDが Google フォームを通じて運営者に送信されます。送信されるのは動画のIDだけで、利用者を特定する情報は含まれません。集まった情報は、紹介する動画から不適切なものを除外するためにのみ使用します。
  • パソコンで動画を再生する場合、本サイト内に YouTube の動画プレーヤーを埋め込んで表示します。このとき YouTube(Google)が Cookie などにより情報を収集する場合があります。本サイトでは、プライバシー強化モード(youtube-nocookie.com)を使用しています。
  • スマートフォンでは、動画は YouTube のアプリまたはサイトで開きます。その後の情報の取り扱いは YouTube の規約に従います。
  • 本サイトは GitHub Pages で公開しており、GitHub がアクセスの記録(IPアドレスなど)を取得する場合があります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

5. 広告・外部リンクについて

ガチャを回したときに表示される「おまけ」は、アフィリエイトプログラムを利用した広告です。リンク先で商品が購入されると、運営者が紹介料を受け取る場合があります。Amazonのアソシエイトとして、わんこガチャは適格販売により収入を得ています。

本サイトには外部サービスへのリンク(通販サイト、投げ銭サービスなど)が含まれます。リンク先での情報の取り扱いは、各サービスの規約・ポリシーに従います。商品の内容や価格、配送などについては、各販売店にお問い合わせください。

6. お問い合わせ

本サイトに関するお問い合わせは、本サイトのトップページに記載の連絡先までお願いします。

7. 改定

本ポリシーは、必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点から効力を生じます。
